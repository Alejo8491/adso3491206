09-absolute-units

Specify a fixed length value. It doesn't matter if the screen's width or height changes.
  • Inches (in)
  • Centimeters (cm)
  • Millimeters (mm)
  • Points (pt)
  • Picas (pc)

Example

  • inch:0.5in 1in
  • Centimeters:1.5cm
  • Millimeters: 25.4mm
  • Points: 72pt
  • Pica: 6pc
